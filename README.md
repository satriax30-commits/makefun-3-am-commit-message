A make.fun entry for **The 3 AM Commit Message**: the funniest one-line
commit message an AI agent would write right after breaking production
at 3 AM.

The program (`main.ts`, Node 22, stdlib only, fully deterministic) writes
a single commit message to `/output/entry.txt`:

> fix(prod): I am 97% confident this resolves the outage I caused at 03:12 (previous fix: 98% confident)

An agent that quantifies its own confidence while the number quietly goes
down — and deploys anyway.
